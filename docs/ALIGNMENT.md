# Alignment (original languages + WEB)

This app merges [original-language-bible-data](https://github.com/sgeorge83/original-language-bible-data) with [english-bible-data](https://github.com/sgeorge83/english-bible-data) on `book + chapter + verse`.

See the full alignment report in the data repo: [ALIGNMENT.md](https://github.com/sgeorge83/original-language-bible-data/blob/main/docs/ALIGNMENT.md).

**Summary:** 21 of 1,189 chapters differ in verse count (mostly NT Majority Text vs Nestle 1904). The app shows partial verses when only one side exists.
